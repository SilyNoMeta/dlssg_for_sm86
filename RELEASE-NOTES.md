# 310.9.1-7 — Correct X3/X4 motion / Corriger le mouvement X3/X4 / 修正 X3/X4 运动

English: Fixes the temporal placement defect behind high X3/X4 FPS with poor apparent smoothness. An 8-pixel X4 translation now progresses through 2/4/6 pixels instead of approximately 4/4/4. The correction is mandatory and applies to DX12 and Vulkan, including with all optimizations disabled. Includes the same four INI options. The exact DLL was tested in Wukong X4 on RTX 3070 Ti Laptop 8 GB: the user reports much smoother motion. 52 offline cases checked. The white Wukong benchmark chart remains; a corrected Vulkan game run remains to be confirmed for this release. No FPS gain is promised. Earlier -0…-6 releases have been withdrawn. [Methods and results](https://github.com/SilyNoMeta/dlssg_for_sm86/blob/feat/dlssg-310.9.1/docs/research.en.md).

Français : corrige le placement temporel des images X3/X4, responsable d'une mauvaise fluidité malgré des FPS élevés. Pour un déplacement X4 de 8 pixels, les sorties progressent désormais à 2/4/6 pixels, contre environ 4/4/4 auparavant. Correction toujours active sur DX12/Vulkan, même avec toutes les optimisations désactivées. Les quatre options INI sont conservées. Cette DLL exacte est confirmée nettement plus fluide en X4 dans Wukong sur RTX 3070 Ti Laptop 8 Go. 52 cas hors jeu vérifiés. Le graphique Wukong reste blanc ; un nouvel essai Vulkan en jeu reste à confirmer pour cette release. Aucun gain de FPS promis. Anciennes releases -0…-6 retirées. [Méthode et résultats](https://github.com/SilyNoMeta/dlssg_for_sm86/blob/feat/dlssg-310.9.1/docs/research.fr.md).

简体中文：修复 X3/X4 虽高 FPS 但运动不流畅的时间位置错误。8 像素运动测试从旧版约 4/4/4 修正为 2/4/6。DX12/Vulkan 均始终应用修正，关闭全部优化也不会关闭修正。保留四项 INI 选项。RTX 3070 Ti Laptop 8 GB 用户确认这个准确的 DLL 在悟空 X4 中明显更流畅，另已检查 52 个离线用例。悟空图表仍为白色；本发布版本的 Vulkan 游戏测试待确认。不承诺 FPS 提升，旧 -0…-6 已撤下。[方法与结果](https://github.com/SilyNoMeta/dlssg_for_sm86/blob/feat/dlssg-310.9.1/docs/research.zh-CN.md)。
