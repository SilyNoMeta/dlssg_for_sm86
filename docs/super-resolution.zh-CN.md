# DLSS 渲染分辨率 — 实验性控件

**DLSS image quality** 控件在所有游戏中均可使用。这是一项实验性功能，
主要用于注入 DLSS 后，游戏本身没有提供 DLSS 画质或渲染比例选项的情况。

**如果游戏已经提供这些选项，请使用游戏的图形菜单，并关闭本插件的覆盖
（`RenderScale=0`）。** 仅凭 DLSS 调用无法可靠判断游戏是否提供相应菜单。
成功注入 DLSS 也不代表渲染比例覆盖一定兼容。

选择预设或自定义比例，然后点击 **Apply scale for this session**。
然后点击 **Save render scale**，将请求保存到 `dlssg_sm86.ini`。
只有观察到 **连续八帧成功的 DLSS 计算使用了请求的分辨率**，才能保存非零比例。
为适应引擎取整，每个轴允许两像素误差。DLL 也执行相同检查：尚未验证、
被忽略、不再匹配或观测已过期的请求无法保存。选择新比例后需要重新应用。
此操作与帧生成设置及快捷键的保存相互独立。

| 按钮 | 渲染宽度与高度的比例 |
|---|---:|
| DLAA | 100% |
| Quality | 66.667% |
| Balanced | 58.824% |
| Performance | 50% |
| Ultra Performance | 33.333% |

滑块范围为 **50–100%**。Ultra Performance 是独立的固定预设，
不支持它与 50% 之间的数值。比例分别作用于宽和高：50% 对应四分之一的像素数。

**请检查“Observed DLSS”。** 该值来自成功的 DLSS 计算中实际使用的分辨率。
请求被接受或保存并不代表已经生效。经过验证的引擎适配器支持实时修改；
其他游戏可能缓存或忽略分辨率建议。保存并重启不能保证生效。

用户报告过：在有原生 DLSS 选项的游戏中保存覆盖后，下次启动失败；
确切原因尚未确认。**如果遇到此情况，请关闭游戏，将 INI 中的 `RenderScale`
设为 `0` 后再启动。** 在游戏中关闭覆盖并应用，可将控制权交还游戏。
实时引擎适配器会恢复之前的比例；其他游戏则自行决定何时重新查询建议值。

不使用 ReShade 时，修改以下配置并重启游戏以重新读取文件：

```ini
[SuperResolution]
RenderScale=0
```

`0` 跟随游戏；`50` 至 `100` 为自定义比例；`33.333` 为 Ultra Performance。
缺失或无效的值回退到 `0`。手动修改会绕过运行时验证，请优先使用面板。
手动修改需要重启才能读取，但重启并不意味着兼容。
保存 `0` 以关闭覆盖始终允许，即使 DLSS 当前未运行。

DLSS 必须已经启用。这些控件只改变渲染分辨率，不切换 K/M 神经网络模型，
也不会为游戏添加 DLSS。请使用配套的引擎 DLL 和 `DLSSGControls.addon64`；
ReShade 插件是可选的控制面板。
